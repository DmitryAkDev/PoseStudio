# Файлы проекта

Файл проекта (`.pss`) сохраняет всю сцену — каждую фигуру с её позой и положением, окружение и камеру — как один небольшой документ, который можно открыть позже или передать другому человеку. Это способ сохранить работу в процессе: закрыть приложение, вернуться, открыть проект, и сцена окажется ровно в том состоянии, в котором вы её оставили.

## Сохранение и открытие

- **Файл → Сохранить** (`Ctrl+S`) записывает сцену в файл проекта. При первом сохранении (и при каждом сохранении после **Сохранить как**) программа спросит, куда сохранить файл; в дальнейшем она будет использовать запомненный путь. Если путь не был задан, **Сохранить** работает как **Сохранить как**.
- **Файл → Сохранить как…** (`Ctrl+Shift+S`) позволяет выбрать новое местоположение для `.pss` и с этого момента делает его файлом проекта. Диалоговое окно откроется в папке, которую вы использовали в прошлый раз; если вы не укажете расширение, к имени будет добавлено `.pss`.
- **Файл → Открыть** (`Ctrl+O`) загружает проект `.pss`. Всё, что в данный момент находится в сцене, заменяется содержимым проекта.

Сохранение весит очень мало — килобайты, а не мегабайты: файл хранит ссылки и числа, но никогда не хранит геометрию или текстуры. Открытие проекта заново импортирует файлы фигур, указанные в нём, через стандартный процесс импорта, и восстанавливает их позы, трансформации, окружение (HDRI и все настройки света) и кадрирование камеры.

## Если файл фигуры был перемещен

Проект указывает путь к исходному файлу каждой фигуры. Если один из этих файлов отсутствует при открытии (был перемещен, переименован или находится на другом компьютере), PoseStudio спросит для каждого отсутствующего файла:

- **Выбрать файл…** перенаправляет ссылку на выбранный вами файл;
- **Пропустить** оставляет эту фигуру без изменений и открывает остальную часть проекта (в предупреждении будет указано, что именно было пропущено);
- **Отмена** полностью прерывает процесс открытия.

Сцена, которая у вас была, остается нетронутой до тех пор, пока все связанные файлы не будут найдены или явно не пропущены, поэтому отмена открытия никогда ничего вам не стоит.

## Несохраненные изменения

PoseStudio отслеживает, изменилась ли сцена с момента последнего сохранения — позирование, перемещение фигуры, импорт, удаление и изменение окружения — всё это учитывается; перемещение камеры — нет (см. [Настройки](preferences.md), чтобы включить учет этого действия). Если есть несохраненные изменения, при нажатии **Новый**, **Открыть** или при закрытии окна программа сначала спросит:

- **Сохранить** записывает проект и продолжает работу;
- **Отбросить изменения** удаляет изменения и продолжает работу;
- **Отмена** оставляет вас в текущем состоянии.

## Формат файла

Файл представляет собой JSON с версионностью, который можно прочитать вручную:

```json
{
  "format": "posestudio.project",
  "version": 1,
  "figures": [
    {
      "source": "C:/figures/hero.duf",
      "transform": {
        "translation": [0.0, 0.0, 0.0],
        "rotation": [0.0, 0.0, 0.0, 1.0],
        "scale": [1.0, 1.0, 1.0]
      },
      "rootBone": "hip",
      "rootTranslation": [0.0, -0.31, 0.12],
      "pose": [
        ["lShldrBend", -40.0, 0.0, 3.2],
        ["rShldrBend", -40.0, 0.0, -3.2]
      ],
      "pins": ["lHand"]
    }
  ],
  "environment": {
    "hdri": "C:/hdris/studio.hdr",
    "settings": { "exposure": 0.65, "keyIntensity": 1.25 }
  },
  "camera": {
    "target": [0.0, 1.0, 0.0],
    "yaw": 0.61,
    "pitch": 0.21,
    "distance": 4.2,
    "ortho": false
  }
}
```

Каждая строка фигуры несет в себе позу так же, как это делает файл `.pose` (повороты костей, смещение `@trans:` корня, закрепленные суставы), плюс её трансформацию — перемещение, вращение в виде кватерниона `[x, y, z, w]`, масштаб. Параметры камеры `yaw` и `pitch` указаны в радианах. Пути к фигурам и панорамам являются абсолютными: если проект открывается на другом компьютере или после перемещения файлов, программа спросит, где находится каждый из них (как описано выше). Неизвестные поля игнорируются при загрузке, поэтому файлы, записанные в более новой версии, откроются в старой; файл из более новой мажорной версии будет отклонен с объяснением, а не загружен наугад. Поврежденный файл — неверный JSON, отсутствующий раздел или нечисловое значение — отклоняется целиком: текущая сцена никогда не заменяется наполовину.
