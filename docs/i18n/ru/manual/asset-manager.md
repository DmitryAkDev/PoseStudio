# Менеджер ассетов

Вкладка **Менеджер ассетов** на боковой панели — это место, где хранится ваш контент. Она просматривает любое количество папок на диске как *библиотеки ассетов*, находит в них ассеты и позволяет собирать ассеты откуда угодно в **Избранное** и вложенные **Коллекции**, не перемещая файлы.

Панель состоит из двух частей с перетаскиваемым разделителем между ними: **дерево** выше (результаты поиска, Избранное, Коллекции и один корень для каждой библиотеки) и **сетка** ниже (миниатюры всего, что вы выбрали в дереве), а под сеткой находится информационная панель, показывающая количество отображаемых элементов.

## Библиотеки ассетов

Библиотека ассетов — это просто папка. PoseStudio поставляется с двумя встроенными:

- **Maquettes** — небольшая встроенная библиотека, идущая в комплекте с приложением.
- **My PoseStudio Library** — создается в вашей папке Documents при первом запуске для вашего собственного контента.

Добавьте свои через **Правка → Настройки → Ассеты → Добавить папку ассетов…** или с помощью ссылки **Добавить папку ассетов**, которая появляется в дереве, если библиотеки еще не созданы. Выберите *корневую* папку библиотеки контента; будут просматриваться все содержимое под ней. Удаление библиотеки на этой же странице лишь отключает папку; с файлами на диске ничего не происходит. В дереве сначала отображается встроенная библиотека, затем ваши по имени папок; если папка библиотеки была удалена, она пропускается.

**Управление папками ассетов** в контекстных меню дерева — это быстрый переход к той же странице «Настройки».

## Что отображается в менеджере ассетов

PoseStudio не знает ваших форматов файлов; она знает миниатюры. **Файл становится ассетом, когда рядом с ним в той же папке лежит изображение с таким же именем**: `Elena.duf` рядом с `Elena.png` — это ассет, отображаемый с этой картинкой; то же самое касается `chair.obj` рядом с `chair.jpg`. Файл без подходящего изображения не отображается, а изображение без подходящего файла — это просто изображение. Распознаваемые типы изображений: png, jpg, jpeg, bmp, webp, gif, tif и tiff; если подходят несколько, используется самое большое. Материалы-сопутствующие файлы (`.mtl`) никогда не отображаются как отдельные ассеты.

Большинство контента для персонажей поставляется именно так — каждый пресет идет со своим превью, — поэтому папка с контентом, добавленная как библиотека, сразу доступна для обзора.

## Обзор

- **Разверните папку** в дереве с помощью стрелки. Папки загружаются при открытии.
- **Нажмите на папку**, чтобы отобразить её ассеты в сетке: сначала подпапки (как ярлыки папок), затем ассеты в алфавитном порядке. Навигационная цепочка над сеткой показывает, где вы находитесь; нажмите на любой сегмент, чтобы перейти туда.
- **Иконки папок** в дереве показывают, содержит ли папка собственные ассеты, содержит ли она их только в подпапках или не содержит вовсе.
- **Двойной клик** по ассету: файлы `.obj`, `.duf` и `.dsf` импортируются во вьюпорт; всё остальное открывается в приложении, которое Windows использует для данного типа файлов. Дважды кликните по ярлыку папки, чтобы войти в папку.
- **Наведите курсор** на ассет, чтобы увидеть его тип файла, размер, дату изменения и папку.
- **Обновить** (в каждом контекстном меню) заново сканирует файлы после того, как вы изменили их на диске.

## Поиск

Введите текст в поле вверху и нажмите `Enter` (или нажмите на значок лупы). Поиск ищет совпадения как в именах файлов, так и в именах папок (регистр не важен) в любой библиотеке. Результаты появляются под заголовком **Результаты поиска** в верхней части дерева в виде папок, содержащих совпадения; нажмите на папку, чтобы увидеть их в сетке. Кнопка очистки (или очистка поля) убирает результаты.

## Избранное

**Избранное** — это единый плоский список ассетов, которые всегда должны быть под рукой. Нажмите правой кнопкой мыши на ассет и выберите **Добавить в избранное** или перетащите его из сетки на *Избранное* в дереве. Нажмите на *Избранное*, чтобы увидеть список; перетаскивайте миниатюры внутри сетки, чтобы изменить порядок — порядок устанавливаете вы, и он сохраняется. **Удалить из избранного** убирает ассет из списка.

## Коллекции

**Коллекции** — это именованные группы ассетов, которые могут иметь любую вложенность — *Characters / Fantasy / Elves* — и могут содержать ассеты из любых библиотек одновременно. Создание и наполнение:

- Нажмите правой кнопкой мыши на **Коллекции** → **Новая коллекция** или правой кнопкой мыши на коллекцию → **Новая подколлекция**. Новая коллекция появится готовой к переименованию; введите имя и нажмите `Enter`.
- Нажмите правой кнопкой мыши на ассет → **Добавить в коллекцию** и выберите существующую коллекцию или *Новая коллекция*. Или **перетащите** ассет на коллекцию в дереве — или на заголовок *Коллекции*, чтобы создать для него новую коллекцию.
- Нажмите правой кнопкой мыши на **папку** → **Добавить в коллекцию**, чтобы создать коллекцию из ассетов этой папки (подпапки не включаются) как новую коллекцию верхнего уровня или внутри существующей.
- Внутри коллекции нажмите правой кнопкой мыши на ассет для команд **Переместить в коллекцию**, **Копировать в коллекцию** и **Удалить из коллекции**. Перетаскивание ассета из одной коллекции на другую перемещает его.
- Перетащите коллекцию на другую (или на заголовок), чтобы переместить её вместе со всем содержимым.
- **Переименовать коллекцию** (или выделите её и нажмите `F2`) переименовывает её на месте. **Удалить коллекцию** доступна только тогда, когда коллекция пуста.

Как и в Избранном, сетка коллекции **сортируема**: перетаскивайте миниатюры, чтобы установить порядок; информационная панель напишет «сортится перетаскиванием», чтобы напомнить вам об этом. Если зажать перетаскиваемый ассет над свернутой коллекцией, она раскроется, чтобы вы могли опустить его глубже.

**Найти в библиотеке** и **Обзор папки**, доступные для ассетов в Избранном, Коллекциях или результатах поиска, переносят дерево к реальной папке ассета или открывают эту папку в Проводнике.

## Контекстные меню

Нажмите правой кнопкой мыши почти на что угодно, чтобы вызвать команды. Вкратце:

| На чем | Команды |
| --- | --- |
| Папка библиотеки в дереве | Добавить в коллекцию, Обзор папки, Развернуть / Развернуть ветку / Свернуть, Управление папками ассетов, Обновить |
| Папка в результатах поиска (Результаты поиска) | Найти в библиотеке, Обзор папки, а затем то же самое, что выше |
| **Коллекции** | Развернуть / Свернуть, Новая коллекция, Управление папками ассетов, Обновить |
| Коллекция | Переименовать коллекцию, Удалить коллекцию, Развернуть / Свернуть, Новая подколлекция, Управление папками ассетов, Обновить |
| **Избранное** | Обновить |
| Пустое место в дереве | Управление папками ассетов, Обновить |
| Ассет в сетке | Открыть (в системном приложении), Найти в библиотеке и Обзор папки (вне режима просмотра библиотеки), Добавить в избранное, Добавить / Переместить / Копировать в коллекцию, Удалить из коллекции или избранного, Обновить |
| Ярлык папки в сетке | Открыть, Найти в библиотеке, Обзор папки, Добавить в коллекцию, Обновить |
| Пустое место в сетке | Обзор папки (для реальной папки), Обновить |

*Открыть* для ассета всегда использует стандартное системное приложение; чтобы импортировать модель или фигуру, вместо этого дважды кликните по ней.
