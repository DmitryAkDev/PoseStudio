# Интерфейс

PoseStudio имеет одно главное окно: панель меню, 3D вьюпорт с плавающей панелью управления и боковую панель с тремя вкладками. Всё остальное — настройки (Preferences), руководство, диалоги импорта — открывается поверх него.

## Главное окно

Вьюпорт расположен слева, а боковая панель — справа; они разделены перетаскиваемым разделителем. В заголовке окна отображается версия ПО, а когда сцена сохранена или открыта как проект, — имя файла проекта (с символом `*` впереди, пока есть несохраненные изменения). Окно открывается в удобном для вашего экрана размере; сохраненный макет (layout) пока отсутствует, поэтому при каждом запуске оно открывается одинаково.

## Панель меню

**Файл** — создание новой сцены, открытие и сохранение сцены как проекта `.pss`, импорт моделей и фигур, сохранение и загрузка поз, а также выход. Серые пункты — «Открыть недавние…», «Сохранить копию…», «Экспорт…» и другие форматы импорта — это заглушки для будущих функций.

| Пункт | Что делает |
| --- | --- |
| Новый (`Ctrl+N`) | Сбрасывает сцену до состояния нового запуска: удаляет все модели, возвращает камеру в исходный вид, восстанавливает стартовое освещение и HDRI, стандартный режим затенения и отключает оверлей скелета, а также очищает историю отмен. Если есть несохраненные изменения, сначала появится запрос: Сохранить, Отменить изменения или Отмена. |
| Открыть… (`Ctrl+O`) | Открывает проект `.pss` — всю сцену. См. [Файлы проекта](project-files.md). |
| Сохранить (`Ctrl+S`) / Сохранить как… (`Ctrl+Shift+S`) | Сохраняет всю сцену как проект `.pss`. См. [Файлы проекта](project-files.md). |
| Импорт → .OBJ (Wavefront) | Импортирует статичную сетку. См. [Импорт контента](importing.md#статические-модели-obj). |
| Импорт → .DUF (файл DUF) | Импортирует фигуру персонажа с ригом. См. [Импорт контента](importing.md#фигуры-персонажей-duf-dsf). |
| Сохранить позу… | Записывает позу активной фигуры в файл `.pose`. |
| Загрузить позу… | Применяет файл `.pose` к активной фигуре (можно отменить). |
| Выход (`Ctrl+Q`) | Закрывает PoseStudio. Если есть несохраненные изменения, сначала появится запрос: Сохранить, Отменить изменения или Отмена. |

**Правка** — история отмен, утилиты для поз и клавиши, которыми можно вращать сустав с помощью мыши.

| Пункт | Что делает |
| --- | --- |
| Отменить (`Ctrl+Z`) / Повторить (`Ctrl+Y`) | Единая история для редактирования поз и освещения. См. [Позирование](posing.md#отмена-и-повтор-действий). |
| Удалить выделенный объект | Удаляет выделенную модель из сцены. Клавиша `Delete` делает то же самое, когда вьюпорт в фокусе. Удаление объекта также очищает историю отмен. |
| Поворачивать сустав мышью → Изгиб (`B`) / Боковой изгиб (`S`) / Скручивание (`T`) | Вращает выбранный сустав при движении мыши; см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t). |
| Сбросить выбранный сустав / Сбросить конечность / Сбросить позу | Возвращает выбранный сустав, сустав и всё, что ниже него, или всю фигуру в исходную позу. |
| Отразить позу / Отразить конечность на другую сторону | Отражает позу по горизонтали или копирует позу выбранной конечности на другую сторону. |
| Настройки | Открывает диалог настроек. |

**Вид** — оверлей скелета и виды камеры (все с помощью горячих клавиш; см. [Навигация во вьюпорте](navigation.md#виды-камеры)).

**Справка** — это руководство (`F1`), список изменений (страница *What's New* в руководстве), веб-сайт, проверка обновлений и окно «О программе». *Туториалы* и *Поддержка* — это заглушки.

## Панель вьюпорта

В правом верхнем углу вьюпорта расположена строка управления:

| Элемент | Что делает |
| --- | --- |
| **Список режимов затенения** (по умолчанию *PBR-затенение*) | Выбирает режим отрисовки сцены. См. [Затенение и отображение](shading.md). |
| **Список видов камеры** (по умолчанию *Исходный вид*) | Привязывает камеру к определенному виду; отображает *Перспектива*, когда вы начинаете вращать камеру. |
| **Home** | Возвращает камеру в исходный вид (также клавиша `5`). |
| **Ground** | Опускает активную фигуру так, чтобы её нижняя точка касалась пола; приземляясь на ноги, она амортизирует падение коленями. См. [Позирование](posing.md#кнопка-ground). |
| **Skeleton** | Показать/скрыть оверлей скелета. Суставы можно захватывать как с включенным, так и с выключенным оверлеем. |

Пока вы вращаете сустав мышью (`B`, `S` или `T` при выбранном суставе: см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t)), под панелью управления появляется небольшая метка с названием движения: Изгиб, Боковой изгиб или Скручивание.

## Боковая панель

Три вкладки расположены на левом краю панели.

- **Менеджер ассетов** — дерево ваших библиотек ассетов, разделы Избранное и Коллекции над сеткой миниатюр, а сверху — поле поиска. Двойной клик по ассету импортирует его. См. [Менеджер ассетов](asset-manager.md).
- **Трансформация** — вращение выбранного сустава представлено в виде трёх дисков: Изгиб, Боковой изгиб и Скручивание. См. [вкладка «Трансформация»](posing.md#вкладка-трансформация).
- **Окружение** — управление освещением: выбор HDRI, фон, экспозиция и тон, освещение на основе изображений, контурный свет, тени, а также акценты на коже и контуре. См. [Освещение и окружение](environment.md).

Вы можете перетащить разделитель между деревом и сеткой в Менеджер ассетов, чтобы увеличить одну из областей.

## Диалоги и оверлеи

- **Настройки** (Правка → Настройки) — это диалог с вкладками по левому краю. Настройки применяются сразу при изменении; кнопка Закрыть — единственная доступная. См. [Настройки](preferences.md).
- **Руководство пользователя** (Справка → Руководство, `F1`) — это текущее окно. Оно всегда находится поверх главного окна, чтобы вы могли читать его во время работы.
- Диалоги **Прогресс импорта** появляются во время загрузки модели или фигуры; у них нет кнопки отмены, и приложение ждёт завершения импорта.
- **Окно «О программе»** (Справка → О PoseStudio) — это заставка с номером версии; нажмите в любом месте, чтобы закрыть её.
