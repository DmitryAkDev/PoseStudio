# Интерфейс

PoseStudio имеет одно главное окно: панель меню, 3D вьюпорт с плавающей панелью управления и боковую панель с тремя вкладками. Все остальное — Настройки, руководство, диалоги импорта — открывается поверх него.

## Главное окно

Вьюпорт расположен слева, а боковая панель — справа; они разделены перетаскиваемым разделителем. В заголовке окна указана версия, которую вы используете, а если сцена сохранена или открыта как проект, то и имя файла проекта — с символом `*` перед ним, пока есть несохраненные изменения. Окно открывается в удобном для вашего экрана размере; сохраненной раскладки еще нет, поэтому оно каждый раз открывается одинаково.

## Панель меню

**Файл** — создание новой сцены, открытие и сохранение сцены как проекта `.pss`, импорт моделей и фигур, сохранение и загрузка поз, а также выход. Серые пункты — Открыть недавние, Сохранить копию, Экспорт и другие форматы импорта — являются заполнителями для планируемых функций.

| Пункт | Что делает |
| --- | --- |
| Новый (`Ctrl+N`) | Сбрасывает сцену до состояния нового запуска: удаляет все модели, возвращает камеру в исходный вид, восстанавливает стартовое освещение и HDRI, режим затенения по умолчанию и отключает оверлей скелета, а также очищает историю отмен. При наличии несохраненных изменений сначала спросит: Сохранить, Отменить изменения или Отмена. |
| Открыть… (`Ctrl+O`) | Открывает проект `.pss` — всю сцену. См. [Файлы проекта](project-files.md). |
| Сохранить (`Ctrl+S`) / Сохранить как… (`Ctrl+Shift+S`) | Сохраняет всю сцену как проект `.pss`. См. [Файлы проекта](project-files.md). |
| Импорт → .OBJ (Wavefront) | Импортирует статичную сетку. См. [Импорт контента](importing.md#статические-модели-obj). |
| Импорт → .DUF (DUF File) | Импортирует фигуру риггерованного персонажа. См. [Импорт контента](importing.md#фигуры-персонажей-duf-dsf). |
| Сохранить позу… | Записывает позу активной фигуры в файл `.pose`. |
| Загрузить позу… | Применяет файл `.pose` к активной фигуре (можно отменить). |
| Выход (`Ctrl+Q`) | Закрывает PoseStudio. При наличии несохраненных изменений сначала спросит: Сохранить, Отменить изменения или Отмена. |

**Правка** — история отмен, утилиты для поз и клавиши, которые позволяют поворачивать сустав мышью.

| Пункт | Что делает |
| --- | --- |
| Отменить (`Ctrl+Z`) / Повторить (`Ctrl+Y`) | Единая история как для редактирования поз, так и для редактирования освещения. См. [Позирование](posing.md#отмена-и-повтор-действий). |
| Удалить выбранный объект | Удаляет выделенную модель из сцены. Клавиша `Delete` делает то же самое, когда вьюпорт находится в фокусе. Удаление объекта также очищает историю отмен. |
| Поворачивать сустав мышью → Изгиб (`B`) / Боковой изгиб (`S`) / Скручивание (`T`) | Поворачивает выбранный сустав при движении мыши; см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t). |
| Сбросить выбранный сустав / Сбросить конечность / Сбросить всё | Возвращает выбранный сустав, сустав и всё, что ниже него, или всю фигуру в исходную позу. |
| Отразить позу / Отразить конечность на другую сторону | Меняет стороны позы местами или копирует позу выбранной конечности на другую сторону. |
| Настройки | Открывает диалог Настройки. |

**Вид** — оверлей скелета и виды камеры (все с использованием горячих клавиш; см. [Навигация во вьюпорте](navigation.md#виды-камеры)).

**Справка** — это руководство (`F1`), список изменений (страница *What's New* в руководстве), веб-сайт, проверка обновлений и окна «О программе». *Туториалы* и *Поддержка* являются заполнителями.

## Панель вьюпорта

В правом верхнем углу вьюпорта парит ряд элементов управления:

| Элемент | Что делает |
| --- | --- |
| **Выбор затенения** (по умолчанию отображается *PBR-затенение*) | Выбирает способ отрисовки сцены. См. [Затенение и отображение](shading.md). |
| **Выбор вида** (по умолчанию отображается *Исходный вид*) | Устанавливает камеру на заданный вид; отображает *Перспективу*, как только вы начнете вращать камеру. |
| **Исходный вид** | Возвращает камеру к стандартному кадрированию (также клавиша `5`). |
| **Земля** | Опускает активную фигуру так, чтобы её самая низкая точка опиралась на пол; приземляясь на ноги, она амортизирует удар коленями. См. [Позирование](posing.md#кнопка-ground). |
| **Скелет** | Показать/скрыть оверлей скелета. Суставы можно захватывать как при включенном, так и при выключенном оверлее. |

Пока мышь вращает сустав (`B`, `S` или `T` при выбранном суставе: см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t)), под панелью появляется небольшая метка с названием движения: Изгиб, Боковой изгиб или Скручивание.

## Боковая панель

Три вкладки расположены на левом краю панели.

- **Менеджер ассетов** — дерево ваших библиотек ассетов, Избранное и Коллекции над сеткой эскизов, а сверху — поле поиска. Двойной клик по ассету импортирует его. См. [Менеджер ассетов](asset-manager.md).
- **Трансформа** — вращение выбранного сустава в виде трех дисков: Изгиб, Боковой изгиб и Скручивание. См. [вкладка «Трансформация»](posing.md#вкладка-трансформация).
- **Окружение** — управление освещением: выбор HDRI, фон, экспозиция и затенение, освещение на основе изображений, контурный свет, тени, а также акценты на коже и контуре. См. [Освещение и окружение](environment.md).

Перетащите разделитель между деревом и сеткой внутри Менеджера ассетов, чтобы выделить больше места любому из них.

## Диалоги и оверлеи

- **Настройки** (Правка → Настройки) — это диалог с вкладками по левому краю. Настройки применяются по мере их изменения; кнопка Закрыть — единственная доступная. См. [Настройки](preferences.md).
- **Пользовательское руководство** (Справка → User Manual, `F1`) — это текущее окно. Оно остается поверх главного окна, чтобы вы могли читать его во время работы.
- Диалоги **прогресса импорта** появляются во время загрузки модели или фигуры; у них нет кнопки отмены, и приложение ждет завершения импорта.
- Экран **О программе** (Справка → About PoseStudio) — это заставка с номером версии; нажмите в любом месте, чтобы закрыть её.
