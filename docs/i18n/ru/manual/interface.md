# Интерфейс

PoseStudio — это одно главное окно: строка меню, 3D-вьюпорт с плавающей панелью управления и боковая панель с тремя вкладками. Всё остальное — Настройки, руководство, диалоги прогресса импорта — открывается поверх него.

## Главное окно

Вьюпорт находится слева, боковая панель — справа, между ними — перетаскиваемый разделитель. В заголовке окна показывается версия программы, а после сохранения или открытия сцены как проекта — ещё и имя файла проекта; впереди стоит `*`, пока есть несохранённые изменения. Окно открывается в удобном для вашего экрана размере; сохранённого макета пока нет, поэтому оно каждый раз открывается одинаково.

## Строка меню

**Файл** — создание новой сцены, открытие и сохранение сцены как проекта `.pss`, импорт моделей и фигур, сохранение и загрузка поз, выход. Серые пункты — Open Recent, Save Copy, Export и другие форматы импорта — заглушки для запланированных функций.

| Пункт | Что делает |
| --- | --- |
| Новый (`Ctrl+N`) | Возвращает сцену в состояние сразу после запуска: удаляет все модели, возвращает камеру в исходное положение, восстанавливает стартовое освещение и HDRI, режим затенения по умолчанию и выключенный оверлей скелета, а также очищает историю отмен. При наличии несохранённых изменений сначала спрашивает: Save, Отменить изменения или Cancel. |
| Open… (`Ctrl+O`) | Открывает проект `.pss` — всю сцену целиком. См. [Файлы проектов](project-files.md). |
| Save (`Ctrl+S`) / Save As… (`Ctrl+Shift+S`) | Сохраняет всю сцену как проект `.pss`. См. [Файлы проектов](project-files.md). |
| Импорт → .OBJ (Wavefront) | Импортирует статический меш. См. [Импорт контента](importing.md#статичные-модели-obj). |
| Импорт → .DUF (DUF File) | Импортирует фигуру персонажа со скелетом. См. [Импорт контента](importing.md#персонажные-фигуры-duf-dsf). |
| Save Pose… | Записывает позу активной фигуры в файл `.pose`. |
| Load Pose… | Применяет файл `.pose` к активной фигуре (с возможностью отмены). |
| Quit (`Ctrl+Q`) | Закрывает PoseStudio. При наличии несохранённых изменений сначала спрашивает: Save, Отменить изменения или Cancel. |

**Правка** — история отмен, утилиты для поз и клавиши, поворачивающие сустав мышью.

| Пункт | Что делает |
| --- | --- |
| Отменить (`Ctrl+Z`) / Повторить (`Ctrl+Y`) | Одна история для правок поз и правок освещения. См. [Позирование](posing.md#отмена-и-повтор). |
| Delete Selected Object | Удаляет обведённый модель из сцены. Клавиша `Delete` делает то же самое, пока вьюпорт в фокусе. Удаление объекта также очищает историю отмен. |
| Поворачивать сустав мышью → Изгиб (`B`) / Боковой изгиб (`S`) / Скручивание (`T`) | Поворачивает выбранный сустав движением мыши; см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t). |
| Сбросить выбранный сустав / Сбросить конечность / Сбросить позу | Возвращает выбранный сустав, сустав вместе со всем, что под ним, или всю фигуру в позу покоя. |
| Отразить позу / Отразить конечность на другую сторону | Меняет стороны позы местами или копирует позу выбранной конечности на другую сторону. |
| Настройки | Открывает диалог Настройки. |

**Вид** — оверлей скелета и виды камеры (у всех есть клавиатурные сокращения; см. [Навигация по вьюпорту](navigation.md#виды-камеры)).

**Справка** — это руководство (`F1`), *What's New…* (список изменений этой версии в отдельном окне — то самое, которое само открывается при первом запуске новой версии, см. [Конфиденциальность и обновления](privacy-updates.md#что-нового-после-обновления)), список изменений (страница *What's New* руководства, полная история), сайт, проверка обновлений и экраны About. *Tutorials* и *Support* — заглушки.

## Панель вьюпорта

Ряд элементов управления плавает в правом верхнем углу вьюпорта:

| Элемент | Что делает |
| --- | --- |
| **Выбор затенения** (по умолчанию показывает *PBR-затенение*) | Выбирает, как рисуется сцена. См. [Затенение и отображение](shading.md). |
| **Выбор вида** (по умолчанию показывает *Home View*) | Привязывает камеру к именованному виду; показывает *Perspective View*, как только вы отходите от вида вращением. |
| **Home** | Возвращает камеру к кадрированию по умолчанию (также `5`). |
| **Ground** | Опускает активную фигуру так, чтобы её нижняя точка оказалась на полу; приземляясь на ноги, она гасит падение коленями. См. [Позирование](posing.md#кнопка-земля). |
| **Skeleton** | Показывает/скрывает оверлей костей. Суставы можно захватывать как с включённым, так и с выключенным оверлеем. |
| **VR** (справа от выбора вида) | Вход в режим VR или выход из него — см. [Режим VR](vr.md); подсвечен синим, пока шлем отображает сцену. Последний пункт выбора вида, VR Mode, делает то же самое, а `Esc` выходит из режима. |

Пока мышь поворачивает сустав (`B`, `S` или `T` при выбранном суставе: см. [Позирование](posing.md#вращение-сустава-мышью-b-s-t)), под панелью появляется небольшой значок с названием движения: Изгиб, Боковой изгиб или Скручивание.

## Боковая панель

Три вкладки расположены на левом краю панели.

- **Менеджер ассетов** — дерево ваших библиотек ассетов, Favorites и Collections над сеткой миниатюр, с полем поиска сверху. Двойной щелчок по ассету импортирует его. См. [Менеджер ассетов](asset-manager.md).
- **Трансформация** — поворот выбранного сустава в виде трёх регуляторов: Изгиб, Боковой изгиб и Скручивание. См. [Вкладка Трансформация](posing.md#вкладка-трансформация).
- **Окружение** — элементы управления освещением: выбор HDRI, фон, экспозиция и затенение, освещение на основе изображений, основной свет, тени, а также акценты кожи и контура. См. [Освещение и окружение](environment.md).

Перетаскивайте разделитель между деревом и сеткой внутри менеджера ассетов, чтобы дать место любому из них.

## Диалоги и оверлеи

- **Настройки** (Правка → Настройки) — диалог со страницами вдоль левой стороны. Настройки применяются сразу при изменении; единственная кнопка — Close. См. [Настройки](preferences.md).
- **Руководство пользователя** (Справка → User Manual, `F1`) — это окно. Оно остаётся поверх главного окна, чтобы вы могли читать его во время работы.
- **Диалоги прогресса импорта** появляются во время загрузки модели или фигуры; у них нет кнопки отмены, и приложение ждёт завершения импорта.
- **Экран About** (Справка → About PoseStudio) — стартовая графика с номером версии; щёлкните в любом месте, чтобы закрыть его.
