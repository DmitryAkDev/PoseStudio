# Конфиденциальность и обновления

PoseStudio выполняет два небольших сетевых запроса, оба необязательны, и больше ничего с вашего компьютера не отправляется. Ваш контент, ваши позы и ваши настройки никогда не загружаются в сеть.

## Анонимный сигнал об установке

Через две секунды после запуска официальная сборка PoseStudio отправляет одно подписанное сообщение на `posestudio.io`, сообщая о том, что данная установка существует. Оно содержит:

- случайный **install ID**, созданный при первой отправке сигнала (UUID: не привязан к вашему компьютеру, аккаунту или чему-либо еще, что может вас характеризовать),
- **версию приложения**,
- название и версию **операционной системы**, а также **архитектуру CPU**,
- информацию о том, была ли программа **установлена или запущена в портативном режиме**,
- **версию библиотеки Qt**,
- **время** отправки сигнала.

И больше ничего — ни имен, ни имен файлов, ни данных об использовании, ни местоположения. Сервер подсчитывает уникальные install ID, благодаря чему проект узнает, сколько людей им пользуются и какие версии сейчас актуальны. Дневного лимита нет; каждый запуск отправляет сигнал, и серверный счетчик позволяет получать точные данные.

Отключите это в меню **Edit → Preferences → General → Отправлять анонимный сигнал об установке**. На этой же странице отображается ваш install ID. Сборка, скомпилированная из исходного кода, не имеет ключа сигнала и ничего не отправляет независимо от этой настройки — об этом говорится на странице.

## Проверка обновлений

Через три секунды после запуска PoseStudio запрашивает у GitHub последний выпуск (release) проекта — это простой запрос к публичному API выпусков, где в качестве user agent выступают только название и версия приложения. Если доступна более новая версия, вы увидите сообщение:

- **Открыть страницу загрузки** открывает страницу выпуска в вашем браузере.
- **Пропустить эту версию** убирает сообщение при запуске для этой версии; если появится еще более новая, она будет предложена снова.
- **Позже** предложит проверить снова при следующем запуске.

Сообщение не блокирует работу; продолжайте работать и ответьте на него, когда захотите. Отключите проверку при запуске в меню **Edit → Preferences → General → Проверять обновления при запуске**.

**Help → Check for Updates…** запускает ту же проверку в любое удобное время и всегда сообщает: доступен новый выпуск, *"You are running the latest release"* или причину, по которой проверка не удалась. Эта команда игнорирует настройку пропуска.

Обновление происходит вручную: скачайте новый установщик или zip-архив со страницы выпуска и запустите его. Установщик обновляет программу на месте, сохраняя вашу библиотеку и настройки.

## Где хранятся ваши данные

| Данные | Расположение | Загружаются? |
| --- | --- | --- |
| Настройки, библиотеки ассетов, коллекции, избранное | `%APPDATA%\PoseStudio\posestudio.db` | Никогда |
| Ваш контент и HDR окружение | Там, где вы их храните; по умолчанию `Documents\My PoseStudio Library` | Никогда |
| Позы | Сохраненные вами файлы `.pose` | Никогда |
| install ID | В базе данных настроек; отображается на странице General | Только в сигнале, если он включен |

**Preferences → Сброс до заводских настроек** удаляет базу данных настроек, включая install ID.
