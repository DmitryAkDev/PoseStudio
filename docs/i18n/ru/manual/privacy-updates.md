# Конфиденциальность и обновления

PoseStudio выполняет два небольших сетевых запроса, оба необязательных, и больше ничего никогда не покидает ваш компьютер. Ваш контент, ваши позы и ваши настройки никогда не загружаются на сервер.

## Анонимный пинг при установке

Через две секунды после запуска официальный сборщик PoseStudio отправляет одно подписанное сообщение на `posestudio.io`, сообщающее, что эта установка существует. Оно содержит:

- случайный **ID установки**, созданный при первой отправке пинга (UUID: не производный от вашей машины, вашей учётной записи или чего-либо ещё о вас),
- **версию приложения**,
- название и версию **операционной системы**, а также **архитектуру CPU**,
- было ли приложение **установлено или запускается портативно**,
- версию библиотеки **Qt**,
- **время** отправки пинга.

Больше ничего — ни имён, ни названий файлов, ни данных об использовании, ни местоположения. Сервер подсчитывает уникальные ID установки — так проект узнаёт, сколько людей им пользуется и какие версии в ходу. Дневного лимита нет: каждый запуск отправляет пинг, а подсчёт на сервере сохраняет честность этих данных.

Отключить: **Правка → Настройки → Общие → Отправлять анонимный пинг при установке**. На той же странице показывается ваш ID установки. Сборка, скомпилированная из исходников, не имеет ключа пинга и ничего не отправляет независимо от настройки — на странице так и написано.

## Проверка обновлений

Через три секунды после запуска PoseStudio запрашивает у GitHub последний выпуск проекта — обычный запрос к публичному API выпусков, где в качестве user agent передаётся только название и версия приложения. Если существует более новая версия, вы получите сообщение:

- **Открыть страницу загрузки** открывает выпуск в браузере.
- **Пропустить эту версию** отключает сообщение при запуске для этой версии; ещё более новая будет предложена снова.
- **Позже** — спросит снова при следующем запуске.

Сообщение вас не блокирует; продолжайте работать и ответьте, когда будет удобно. Отключить проверку при запуске: **Правка → Настройки → Общие → Проверять обновления при запуске**.

**Справка → Проверить обновления…** выполняет ту же проверку в любой момент и всегда сообщает результат — о более новом выпуске, *«У вас установлена последняя версия»* или о том, почему проверка не удалась. Она игнорирует настройку пропуска.

Обновление выполняется вручную: скачайте новый установщик или zip со страницы выпуска и запустите его. Установщик обновляет программу на месте и сохраняет вашу библиотеку и настройки.

## Что нового после обновления

При первом запуске новой версии PoseStudio открывает **Что нового в PoseStudio x.y.z** сразу после того, как вы закроете экран загрузки: список изменений версии, которую вы сейчас используете — что добавлено, изменено и исправлено — в отдельном прокручиваемом окне. Оно появляется один раз на версию (при новой установке оно тоже показывается — для установленной версии). **Список изменений** в окне открывает полную историю в этом руководстве; **Закрыть** (или `Enter` / `Esc`) убирает окно.

**Справка → Что нового…** открывает то же окно в любой момент. Чтобы оно не открывалось само, снимите флажок **Показывать это окно после обновления** в самом окне либо **Правка → Настройки → Общие → Показывать «Что нового» после обновления**.

## Где хранятся ваши данные

| Данные | Расположение | Загружаются? |
| --- | --- | --- |
| Настройки, библиотеки ассетов, коллекции, избранное | `%APPDATA%\PoseStudio\posestudio.db` | Никогда |
| Ваш контент и HDRI-окружения | Там, где вы их храните; по умолчанию `Documents\My PoseStudio Library` | Никогда |
| Позы | Файлы `.pose`, которые вы сохраняете | Никогда |
| ID установки | В базе данных настроек; показывается на странице «Общие» | Только в пинге, если он включён |

Настройки → Сброс до заводских настроек удаляет базу данных настроек, включая ID установки.
