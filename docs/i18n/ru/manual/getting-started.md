# Начало работы

Эта страница проведет вас от чистой установки до вашей первой позы фигуры.

## Системные требования

- **Windows 10 или 11** (64-бит). Сборки для macOS и Linux планируются; код кроссплатформенный, но на данный момент протестирована и поставляется только сборка для Windows.
- Видеокарта и драйвер с поддержкой **Vulkan**. Подходит любая видеокарта последних нескольких лет — если PoseStudio не сможет создать экземпляр Vulkan, приложение запустится, но вместо 3D вьюпорта появится сообщение с предложением обновить драйвер видеокарты (см. [Устранение неполадок](troubleshooting.md#вьюпорт-сообщает-что-vulkan-недоступен)).
- Достаточный объем памяти для вашего контента: полностью текстурированная фигура персонажа может занимать несколько сотен мегабайт видеопамяти, так как её текстуры декодируются в разрешении до 4096 × 4096 пикселей.

## Установка

Выпуски доступны в двух вариантах, оба доступны на [странице релизов GitHub](https://github.com/PoseStudio/PoseStudio/releases) проекта:

- **Установщик** — установка для пользователя, не требующая прав администратора. Он помещает стартовый набор HDRI окружений в вашу папку Documents (см. ниже), добавляет записи в меню «Пуск» и деинсталлятор, а также позволяет обновиться до более поздней версии на том же месте.
- **Портативный zip-архив** — распакуйте где угодно и запустите `PoseStudio.exe`. Ничего не записывается за пределами вашего пользовательского профиля.

Оба варианта включают в себя всё необходимое для работы приложения, включая Visual C++ runtime и загрузчик Vulkan. Установщик еще не имеет цифровой подписи, поэтому при первом запуске Windows SmartScreen может выдать предупреждение; если вы скачали его со страницы релизов, выберите *Подробнее → Все равно* (More info → Run anyway).

## Первый запуск

При первом запуске PoseStudio:

- Создает базу данных настроек в вашем пользовательском профиле (`AppData\Roaming\PoseStudio` в Windows). Ваши папки ассетов, коллекции, избранное и настройки хранятся именно там, а не рядом с исполняемым файлом.
- Создает папку **My PoseStudio Library** в вашей папке Documents и регистрирует её как библиотеку ассетов. Это место для вашего собственного контента; подпапка `hdri` — это место, где PoseStudio ищет HDRI окружения (установщик помещает туда стартовый набор; портативная сборка запускается без них и использует встроенное студийное окружение, пока вы не добавите свои).
- Показывает сплэш-скрин. Нажмите в любом месте, чтобы закрыть его — тот же экран открывается через **Help → About PoseStudio**.

Через несколько секунд после каждого запуска приложение отправляет анонимный сигнал «эта установка существует» и проверяет GitHub на наличие более свежего релиза. Оба действия можно отключить в **Edit → Preferences → General**; подробности о том, что именно отправляется, см. в [Конфиденциальность и обновления](privacy-updates.md).

## Обзор окна

- **Меню** — File, Edit, View и Help.
- **3D вьюпорт** занимает большую часть окна. В его верхнем правом углу находится панель управления: выбор режима затенения, выбор вида камеры, а также кнопки Home, Ground и Skeleton.
- **Боковая панель** справа имеет три вкладки на левом краю: **Менеджер ассетов** (ваш контент), **Трансформация** (вращение выделенного сустава) и **Окружение** (освещение). Вы можете изменить размер вьюпорта и панели, перетащив разделитель между ними.

В разделе [Интерфейс](interface.md) каждая часть описана подробно.

## Ваша первая фигура

1. **Импортируйте фигуру.** Используйте **File → Import → .DUF (DUF File)** и выберите пресет персонажа, либо добавьте папку с вашими фигурами как библиотеку ассетов и дважды щелкните по одной из них в Менеджер ассетов. В диалоговом окне прогресса отображаются этапы (чтение, декодирование текстур, запекание окружающей окклюзии, загрузка); на отображение полностью текстурированной фигуры уходит несколько секунд. Фигура появится стоящей на полу, лицом к вам, в поле зрения камеры. Если PoseStudio попросит вас указать папку с контентом, см. [Импорт контента](importing.md#если-данные-фигуры-не-найдены).
2. **Осмотритесь.** Перетаскивайте мышью по пустому пространству, чтобы вращать камеру, используйте среднюю кнопку мыши для панорамирования, крутите колесико для масштабирования. Нажмите `1`, `3` или `7` для видов спереди, справа и сверху, нажмите `5`, чтобы вернуться к исходному виду.
3. **Поза.** Перетаскивайте любую часть тела. Возьмите руку и потяните её вверх — рука поднимется, а тело наклонится; потяните сильнее, и она встанет на носочки. Возьмите таз и потяните его вниз — она присядет. Отведите таз назад, и она сделает шаг. Отпустите кнопку, и поза зафиксируется; `Ctrl+Z` отменит действие. В [Позирование](posing.md) объясняется всё, на что способно тело, а в [Создание поз шаг за шагом](poses.md) показано, как сделать коленопреклонение, посадку, положение лежа, положение на четвереньках и многое другое.
4. **Настройте свет.** Откройте вкладку **Окружение**, выберите HDRI из списка и настройте экспозицию и контурный свет. Изображение обновляется в реальном времени.
5. **Сохраните работу.** **File → Save** (`Ctrl+S`) записывает всю сцену — фигуру, её позу, освещение и камеру — в файл проекта `.pss`, который можно снова открыть через **File → Open**; см. [Файлы проекта](project-files.md). **File → Save Pose…** записывает только позу фигуры в файл `.pose`, который можно загрузить на любую другую фигуру позже; см. [Файлы поз](pose-files.md).

## Где что находится

| Что | Где |
| --- | --- |
| Ваши настройки, библиотеки ассетов, коллекции, избранное | `%APPDATA%\PoseStudio\posestudio.db` |
| Ваша библиотека контента (добавленные вами ассеты, HDRI окружения) | `Documents\My PoseStudio Library` |
| HDRI окружения | `Documents\My PoseStudio Library\hdri` (подпапки становятся категориями) |
| Встроенная библиотека образцов ("Maquettes") | Рядом с исполняемым файлом |
| Сохраненные вами позы и проекты | Там, где вы выберете; последняя использованная папка запоминается |

Ничто из импортированного не копируется и не изменяется: PoseStudio считывает ваши файлы там, где они лежат.
