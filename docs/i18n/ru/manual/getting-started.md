# Начало работы

Эта страница проведёт вас от свежей установки до первой поставленной фигуры.

## Системные требования

- **Windows 10 или 11** (64-бит). Сборки для macOS и Linux запланированы; код кроссплатформенный, но сейчас тестируется и поставляется только сборка для Windows.
- Видеокарта и драйвер с поддержкой **Vulkan**. Подойдёт любой GPU последних нескольких лет — если PoseStudio не может создать Vulkan-инстанс, приложение всё равно запускается, но 3D-вьюпорт заменяется сообщением с просьбой обновить графический драйвер (см. [Устранение неполадок](troubleshooting.md#вьюпорт-сообщает-что-vulkan-недоступен)).
- Достаточно памяти для вашего контента: полностью текстурированная фигура персонажа может занимать несколько сотен мегабайт видеопамяти, так как её текстуры декодируются вплоть до 4096 × 4096 пикселей.

## Установка

Выпуски поставляются в двух формах, обе — со [страницы выпусков проекта на GitHub](https://github.com/PoseStudio/PoseStudio/releases):

- **Установщик** — установка для одного пользователя, не требующая прав администратора. Он размещает стартовый набор HDR-окружений в папке «Документы» (см. ниже), добавляет ярлыки в меню «Пуск» и деинсталлятор, а также позволяет более поздней версии обновиться на месте.
- **Портативный zip** — распакуйте в любое место и запустите `PoseStudio.exe`. Ничего не записывается за пределами вашего профиля пользователя.

Оба варианта включают всё, что нужно приложению, включая среду выполнения Visual C++ и загрузчик Vulkan. Установщик пока не подписан кодом, поэтому Windows SmartScreen может предупредить при первом запуске; выберите *Подробнее → Выполнить в любом случае*, если вы скачали его со страницы выпусков.

## Первый запуск

При первом старте PoseStudio:

- Создаёт базу настроек в вашем профиле пользователя (`AppData\Roaming\PoseStudio` на Windows). Ваши папки ассетов, коллекции, избранное и настройки хранятся там — а не рядом с исполняемым файлом.
- Создаёт **My PoseStudio Library** в папке «Документы» и регистрирует её как библиотеку ассетов. Это дом для вашего собственного контента; её подпапка `hdri` — то место, где PoseStudio ищет HDR-окружения (установщик кладёт стартовый набор туда; портативная сборка стартует без них и использует встроенное студийное окружение, пока вы не добавите свои).
- Показывает заставку. Щёлкните в любом месте, чтобы её убрать — тот же экран доступен через **Справка → О PoseStudio**.

Через несколько секунд после каждого запуска приложение отправляет анонимный пинг «эта установка существует» и проверяет GitHub на наличие более нового выпуска. И то и другое можно отключить в **Правка → Настройки → Общие**; о том, что именно отправляется, см. [Приватность и обновления](privacy-updates.md).

## Окно с первого взгляда

- **Строка меню** — Файл, Правка, Вид и Справка.
- **3D-вьюпорт** занимает большую часть окна. В его правом верхнем углу плавает полоса элементов управления: выбор затенения, выбор вида камеры и кнопки Исходный вид, Пол и Скелет.
- **Боковая панель** справа имеет три вкладки на своём левом краю: **Менеджер ассетов** (ваш контент), **Трансформация** (поворот выбранного сустава) и **Окружение** (освещение). Перетащите разделитель между вьюпортом и панелью, чтобы изменить их размер.

[Интерфейс](interface.md) подробно описывает каждую часть.

## Ваша первая фигура

1. **Импортируйте фигуру.** Используйте **Файл → Импорт → .DUF (DUF File)** и выберите пресет персонажа, либо добавьте папку с вашими фигурами как библиотеку ассетов и дважды щёлкните по одной из них в Менеджере ассетов. Диалог прогресса показывает этапы (чтение, декодирование текстур, запекание AO, загрузка); полностью текстурированная фигура занимает несколько секунд. Фигура появляется стоящей на полу, лицом к вам, вписанной в кадр камеры. Если PoseStudio просит указать папку с контентом, см. [Импорт контента](importing.md#когда-данные-фигуры-не-найдены).
2. **Осмотритесь.** Перетаскивайте по пустому месту для вращения, перетаскивайте средней кнопкой для панорамирования, крутите колесо для зума. Нажмите `1`, `3` или `7` для видов спереди, справа и сверху, `5` — чтобы вернуться к виду по умолчанию.
3. **Позируйте.** Перетаскивайте любую часть тела. Возьмите руку и потяните вверх — рука поднимается, а тело наклоняется; потяните дальше — она приподнимается на носки. Возьмите бёдра и потяните вниз — она приседает. Отведите бёдра назад — она делает шаг. Отпустите — и поза сохранится; `Ctrl+Z` её отменяет. [Позирование](posing.md) объясняет всё, что умеет тело, а [Позы шаг за шагом](poses.md) показывает, как сделать позу на коленях, сидя, лёжа, на четвереньках и другие.
4. **Осветите.** Откройте вкладку **Окружение**, выберите HDRI из списка и настройте экспозицию и основной свет. Картинка обновляется в реальном времени.
5. **Сохраните работу.** **Файл → Сохранить** (`Ctrl+S`) записывает всю сцену — фигуру, её позу, освещение и камеру — в файл проекта `.pss`, который можно снова открыть через **Файл → Открыть**; см. [Файлы проектов](project-files.md). **Файл → Сохранить позу…** записывает только позу фигуры в файл `.pose`, который позже можно загрузить на любую фигуру; см. [Файлы поз](pose-files.md).

## Где что находится

| Что | Где |
| --- | --- |
| Ваши настройки, библиотеки ассетов, коллекции, избранное | `%APPDATA%\PoseStudio\posestudio.db` |
| Ваша библиотека контента (добавленные ассеты, HDR-окружения) | `Documents\My PoseStudio Library` |
| HDR-окружения | `Documents\My PoseStudio Library\hdri` (подпапки становятся категориями) |
| Встроенная примерная библиотека («Maquettes») | Рядом с исполняемым файлом |
| Сохранённые позы и проекты | Там, где вы выберете; последняя папка для каждого запоминается |

Ничего из импортированного не копируется и не изменяется: PoseStudio читает ваши файлы там, где они лежат.
