# Файлы поз

Поза сохраняется в виде небольшого текстового файла `.pose`, который можно загрузить на фигуру, сохранить в библиотеке или передать кому-то другому.

## Сохранение и загрузка

- **Файл → Сохранить позу…** записывает текущую позу активной фигуры. Диалоговое окно открывается в папке, которую вы использовали в прошлый раз; если вы не введете расширение вручную, `.pose` будет добавлено к имени автоматически. Любое движение, которое еще не завершилось, сначала фиксируется, поэтому файл сохраняет именно ту позу, которую вы видите.
- **Файл → Загрузить позу…** применяет `.pose` файл к активной фигуре — вращение каждого сустава, положение фигуры и её закрепленные суставы — как один шаг, который можно отменить: `Ctrl+Z` вернет предыдущую позу.
- Для обоих действий в сцене должна быть фигура; если её нет, PoseStudio сообщит об этом и ничего не сделает.
- Если передать `.pose` файл через командную строку или перетащить его на `PoseStudio.exe` после загрузки фигуры, он применится к этой фигуре сразу после её загрузки.

Файл позы содержит названия костей фигуры, поэтому он лучше всего подходит для той фигуры, из которой был сохранен, или для другой фигуры того же поколения, у которой кости называются так же. Если загрузить файл на фигуру с другими названиями костей, суставы, которые не удалось найти, будут пропущены и останутся в исходном положении.

Позы, сохраненные в версии 0.3.15 или ранее, могут загружаться немного иначе: в тех версиях каждый сустав поворачивался вокруг осей, которые немного отличались от осей самой фигуры, что было наиболее заметно на больших пальцах, пальцах рук, предплечьях и стопах. Теперь вращения в файле применяются вокруг правильных осей.

## Закрепленные суставы перемещаются вместе с позой

Суставы, которые вы закрепили при сохранении, будут закреплены снова при загрузке. Старые файлы без строк с закрепленными суставами загружаются без проблем — они просто не устанавливают закрепления.

## Формат файла

Файл является текстовым, по одной строке на строку, и его можно редактировать вручную:

```
hip 0 12.5 0
lShldrBend -40 0 3.2
rShldrBend -40 0 -3.2
@trans:hip 0 -0.31 0.12
@pin:lHand 0.21 0.95 0.14
```

Могут встречаться три типа строк:

| Строка | Значение |
| --- | --- |
| `bone rx ry rz` | Вращение кости в градусах в порядке вращения, установленном для этого сустава у фигуры. |
| `@trans:bone x y z` | Смещение положения кости в метрах (полнотелый IK записывает одно такое смещение для корня: при приседе или ходьбе). |
| `@pin:bone x y z` | Закрепленный сустав и его положение. |

Загрузка начинается с исходной позы, после чего применяются строки: сустав, который не указан в файле, возвращается в исходное положение, строка с названием кости, которой нет у фигуры, игнорируется, а закрепленные суставы из файла заменяют текущие. Файл с поврежденной строкой (пропущенное число, нечисловое значение) отклоняется целиком (*"Could not read the pose file."*), а не применяется частично. При загрузке значения вращения приводятся к диапазону ±360°, а затем ограничиваются пределами каждого сустава.
