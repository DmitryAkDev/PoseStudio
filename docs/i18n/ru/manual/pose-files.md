# Файлы поз

Поза сохраняется в небольшой текстовый файл `.pose`, который можно снова загрузить на фигуру, хранить в своей библиотеке или передать кому-то ещё.

## Сохранение и загрузка

- **Файл → Сохранить позу…** записывает текущую позу активной фигуры. Диалог открывается в папке, которую вы использовали в прошлый раз; если `.pose` отсутствует в имени, он добавляется автоматически. Любое ещё догорающее перетаскивание сначала завершается, так что файл содержит именно ту позу, которую вы видите.
- **Файл → Загрузить позу…** применяет файл `.pose` к активной фигуре — повороты всех суставов, положение фигуры и её закрепления — как один шаг с возможностью отмены: `Ctrl+Z` возвращает предыдущую позу.
- Для обоих действий нужна фигура в сцене; если её нет, PoseStudio сообщит об этом и ничего не сделает.
- Файл `.pose`, переданный в командной строке или брошенный на `PoseStudio.exe` после загрузки фигуры, применяется к этой фигуре, как только она загрузится.

Файл позы называет кости фигуры, поэтому лучше всего он подходит той фигуре, с которой был сохранён, — или другой фигуре того же поколения, которая называет кости так же. При загрузке на фигуру с другими именами костей суставы, которые не удаётся найти, пропускаются и остаются в покое. Персонажи, импортированные из FBX-файлов, всегда используют стандартные имена костей рига (см. [Импорт контента](importing.md)) и стандартные системы поворотов и диапазонов, поэтому поза, сохранённая на одном из них, загрузится на любом другом, каким бы инструментом они ни были риггованы; поза от нативной фигуры не переносится на них, а их — на нативную фигуру.

Позы, сохранённые в версии 0.3.15 или более ранней, могут загружаться немного иначе: в тех версиях каждый сустав поворачивался вокруг осей, слегка смещённых относительно собственных осей фигуры, — заметнее всего на больших пальцах, пальцах, предплечьях и ступнях. Теперь повороты из файла применяются вокруг правильных осей.

## Закрепления следуют за позой

Суставы, которые вы закрепили при сохранении, снова закрепляются при загрузке. Старые файлы без строк закреплений загружаются нормально — они просто не задают закреплений.

## Формат файла

Файл — текстовый, по одной строке на запись, и его можно править вручную:

```
hip 0 12.5 0
lShldrBend -40 0 3.2
rShldrBend -40 0 -3.2
@trans:hip 0 -0.31 0.12
@pin:lHand 0.21 0.95 0.14
```

Могут встречаться три вида строк:

| Строка | Значение |
| --- | --- |
| `bone rx ry rz` | Поворот кости в градусах, в собственном порядке поворотов фигуры для этого сустава. |
| `@trans:bone x y z` | Смещение положения кости в метрах (полнотелый IK записывает такое для корня: приседание, шаг). |
| `@pin:bone x y z` | Закреплённый сустав и место, где он удерживается. |

Загрузка начинается из позы покоя и применяет строки: сустав, не названный в файле, возвращается в покой, строка, называющая кость, которой у фигуры нет, игнорируется, а закрепления из файла заменяют текущие. Файл с повреждённой строкой — пропущенным числом, нечисловым значением — отклоняется целиком (*«Не удалось прочитать файл позы.»*), а не применяется наполовину. Повороты при загрузке приводятся в диапазон ±360°, а затем ограничиваются пределами сгиба каждого сустава.
