# Затенение и отображение

**Выбор затенения** на панели вьюпорта определяет, как отрисовывается сцена. Переключение происходит мгновенно и никогда не влияет на позу или настройки освещения — оно меняет только то, что вы видите. Восемнадцать режимов выбора делятся на четыре группы.

## Освещенное затенение реальных материалов

| Mode | Что вы видите |
| --- | --- |
| **PBR-затенение** (по умолчанию) | Фотореалистичный режим: физически корректные материалы, освещенные HDR-окружением и основным светом, с полупрозрачностью кожи, подповерхностным рассеиванием, мягкими тенями, эффектом bloom и тональной компрессией ACES filmic. Единственный режим, который отображает HDRI-фон и реагирует на каждый регулятор на вкладке Окружение. |
| **Текстурное затенение** | Текстурированные материалы при простой трехточечной студийной схеме освещения. Быстро, равномерно и прощает ошибки. |
| **Затенение текстурой (плоское)** | То же самое, но с затенением по каждой грани — видны фасетки поверхности. |
| **Мультяшное затенение** | Ступенчатое затенение в стиле сел-шейдинга с использованием текстур. |

## Формальные исследования без текстур

| Mode | Что вы видите |
| --- | --- |
| **Matcap** | Нейтральная сфера со студийным материалом, наложенная на каждую поверхность — взгляд скульптора на форму, не зависящий от света. |
| **Глиняное затенение** | Матовая, равномерно освещенная глина. |
| **Только свет** | Белый материал под светом с бликами — для оценки самого освещения. |
| **Силуэт** | Один плоский заполняющий свет: только контур позы и ничего больше. |

## Каркас

| Mode | Что вы видите |
| --- | --- |
| **Каркас** | Каждое ребро, без поверхности. |
| **Каркас с невидимыми линиями** | Ребра, обращенные к вам, при этом скрытые ребра удалены — поверхность перекрывает объекты, но не отрисовывается. |
| **Глиняное затенение Каркас** | Глиняная поверхность с отрисованными поверх неё ребрами. |
| **Текстурное затенение Каркас** | Текстурированная поверхность с отрисованными поверх неё ребрами. |

Для режимов Каркас требуется видеодрайвер с поддержкой отрисовки линий (все десктопные драйверы это поддерживают); если ваш драйвер не поддерживает это, режимы каркаса будут показывать только поверхность.

## Режимы отображения данных

Они показывают один из компонентов материала или освещения, чтобы проверить содержимое, а не для визуального осмотра:

| Mode | Что вы видите |
| --- | --- |
| **Альбедо** | Диффузные карты цвета без освещения. |
| **Окружающая окклюзия (AO)** | Запеченная окружающая окклюзия (AO) в виде серого цвета. |
| **Карта шероховатости** | Шероховатость материалов в виде серого цвета: черный — глянцевый, белый — матовый. |
| **Только блики** | Только блики режима PBR. |
| **Нормали** | Нормали поверхности в виде цвета. |
| **Проверка UV** | Шахматный узор, наложенный через текстурные координаты модели. |

## Контур выделения

Выделенная модель имеет синий контур. Он отрисовывается по всему силуэту объекта, поэтому остается видимым сквозь любые объекты перед ним. Процесс выделения описан в [Навигация во вьюпорте](navigation.md#выбор-объектов).

## Наложение скелета

**Вид → Показать скелет** и кнопка **Скелет** на панели отрисовывают кости фигуры в виде линий от каждого сустава к его родителю. По умолчанию наложение выключено, так как оно не обязательно: суставы можно захватывать прямо на теле, а часть тела, которой управляет выбранный сустав, подсвечивается синим, чтобы вы видели, за что держитесь. Включите наложение, когда вам нужно увидеть точное расположение суставов — например, чтобы найти кость скручивания (twist) в середине конечности.

## Сглаживание и изображение

Вьюпорт рендерится с многократным сглаживанием (4×, если видеокарта это поддерживает) и в широком динамическом диапазоне; изображение в режиме PBR проходит через подповерхностное рассеивание для кожи, эффект bloom для самых ярких бликов и тональную компрессию ACES filmic, прежде чем попасть на экран. Другие режимы пропускают эту цепочку и отображают свои цвета напрямую. Рендеринг происходит только при изменениях, поэтому в режиме ожидания PoseStudio не потребляет ресурсов графического процессора.
