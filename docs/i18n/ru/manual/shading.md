# Затенение и отображение

**Шейдерный переключатель** на панели вьюпорта (в подсказке указано *Viewport shading mode*) определяет способ отрисовки сцены. Переключение происходит мгновенно и не влияет на позу или настройки освещения — оно меняет только то, что вы видите. Восемнадцать режимов переключателя разделены на четыре группы.

## Затенение с учетом освещения реальных материалов

| Mode | Что вы видите |
| --- | --- |
| **PBR-затенение** (по умолчанию) | Фотореалистичный режим: физически корректные материалы, освещенные HDR-окружением и основным светом, с полупрозрачностью кожи, подповерхностным рассеиванием, мягкими тенями, эффектом bloom и тональной компрессией ACES filmic. Единственный режим, который отображает HDRI-фон и реагирует на каждый регулятор на вкладке Окружение. |
| **Текстурное затенение** | Текстурированные материалы при простом трехточечном студийном освещении. Быстро, равномерно и прощает ошибки. |
| **Затенение текстурой (плоское)** | То же самое, но с пофасетным затенением — видны грани поверхности. |
| **Мультяшное затенение** | Ступенчатое затенение в стиле сел-шейдинга с текстурами. |

## Формальные наброски без текстур

| Mode | Что вы видите |
| --- | --- |
| **MatCap** | Нейтральный студийный материал-сфера, примененный к каждой поверхности — взгляд скульптора на форму, не зависящий от света. |
| **Глиняное затенение** | Матовая, равномерно освещенная глина. |
| **Только свет** | Белый материал под светом с бликами — для оценки самого освещения. |
| **Силуэт** | Один плоский заполняющий свет: только контур позы и ничего больше. |

## Каркас

| Mode | Что вы видите |
| --- | --- |
| **Каркас** | Каждое ребро, без поверхности. |
| **Каркас со скрытыми линиями** | Ребра, обращенные к вам, при этом скрытые ребра удалены — поверхность перекрывает, но не отрисовывается. |
| **Глиняное затенение Каркас** | Глиняная поверхность с отрисованными поверх неё ребрами. |
| **Текстурное затенение Каркас** | Текстурированная поверхность с отрисованными поверх неё ребрами. |

Для режимов Каркас требуется видеодрайвер с поддержкой отрисовки линий (все десктопные драйверы это поддерживают); если ваш драйвер не поддерживает это, режимы Каркас будут показывать только поверхность.

## Режимы отображения данных

Они показывают один из компонентов материала или освещения, чтобы проверить содержимое, а не для визуального осмотра:

| Mode | Что вы видите |
| --- | --- |
| **Альбедо** | Диффузные карты цвета без освещения. |
| **Окружающая окклюзия (AO)** | Запеченная окружающая окклюзия (AO) в виде серого цвета. |
| **Карта шероховатости** | Шероховатость материалов в виде серого цвета: черный — глянцевый, белый — матовый. |
| **Только блики** | Только блики режима PBR. |
| **Нормали** | Нормали поверхности в виде цвета. |
| **Проверка UV** | Шахматный узор, наложенный через текстурные координаты модели. |

## Контур выделения

Выделенная модель имеет синий контур. Он рисуется вокруг всего силуэта объекта, поэтому остается видимым сквозь любые объекты перед ним. Описание процесса выбора приведено в [Навигация во вьюпорте](navigation.md#выбор-объектов).

## Отображение скелета

**Вид → Показать скелет** и кнопка **Skeleton** на панели рисуют кости фигуры в виде линий от каждого сустава к его родителю. По умолчанию эта функция выключена, так как она не обязательна: суставы можно захватывать прямо на теле, а часть тела, которой управляет выбранный сустав, подсвечивается синим, чтобы вы видели, за что именно держитесь. Включите отображение скелета, когда вам нужно точно видеть расположение суставов — например, чтобы найти кость скручивания (twist) в середине конечности.

## Сглаживание и изображение

Вьюпорт рендерит с многократным сглаживанием (4×, если видеокарта это поддерживает) и в широком динамическом диапазоне; изображение в режиме PBR проходит через подповерхностное рассеивание для кожи, bloom для самых ярких бликов и тональную компрессию ACES filmic, прежде чем попасть на экран. Другие режимы пропускают эту цепочку и отображают свои цвета напрямую. Рендеринг происходит только при изменениях, поэтому в режиме ожидания PoseStudio не потребляет ресурсов графического процессора.
