# Справочник по клавиатуре и мыши

Все элементы управления в одном месте. «Фокус во вьюпорте» означает, что вы кликнули в 3D-вид после последнего использования другой панели; остальные горячие клавиши работают независимо от того, какая панель в фокусе (текстовое поле, в котором вы печатаете, сохраняет свои клавиши).

## Мышь во вьюпорте

| Жест | Где | Что делает |
| --- | --- | --- |
| Зажатая левая кнопка | на суставе | IK всего тела: захваченная точка следует за курсором, тело следует анатомически. |
| Зажатая левая кнопка | на пальце руки или ноги | Только этот палец сгибается к курсору; кисть, стопа и тело остаются на месте (с Ctrl или без него). |
| Зажатая левая кнопка | на пустом месте или на теле модели | Орбитальное вращение камеры. |
| Ctrl + зажатая левая кнопка | на конечности, голове или торсе | Ограниченный IK: следует только цепочка, к которой принадлежит сустав — конечность до тела, голова и шея, торс до таза. Больше ничего не двигается; закреплённые суставы ниже по цепочке остаются на своих местах. |
| Ctrl + зажатая левая кнопка | на бёдрах | Перемещает всю фигуру в текущей позе: ничего не привязано к полу, ни один сустав не поворачивается. Закреплённые суставы остаются на своих местах. |
| Левый клик | на модели | Выделить её (синяя обводка); клик по пустому месту снимает выделение. |
| Левый клик | на суставе | Выделить сустав (и сделать его фигуру активной). Клик по лицу выделяет голову; клик по ладони или тыльной стороне кисти выделяет кисть. |
| Shift + левый клик | на суставе | Добавить сустав к выделению или убрать выделенный сустав из него. |
| Shift + зажатая левая кнопка | на выделенном суставе | Переместить все выделенные суставы вместе, на одинаковое расстояние; тело следует, как при обычном перетаскивании. |
| Зажатая средняя кнопка | где угодно | Панорамирование. |
| Колесо | обычно | Масштабирование. |
| Колесо | во время перетаскивания сустава левой кнопкой | Приблизить захваченную точку к камере (прокрутка вниз) или отдалить от неё (прокрутка вверх). |
| Правый клик | на модели или суставе | Контекстное меню: закрепить / открепить, сбросить сустав или конечность, отразить конечность, удалить. |

## Камера

| Клавиша | Действие |
| --- | --- |
| `1` / `Ctrl+1` | Вид спереди / сзади |
| `3` / `Ctrl+3` | Вид справа / слева |
| `7` / `Ctrl+7` | Вид сверху / снизу |
| `9` | Вид с другой стороны, поворот на 180° |
| `5` | Исходный вид (компоновка по умолчанию) |
| `.` | Вписать выделенную модель |

Клавиши работают и в верхнем ряду цифр, и на цифровой клавиатуре. При выключенном NumLock клавиши `End` / `PageDown` / `Home` / `PageUp` / `Clear` (5) / `Del` на цифровой клавиатуре заменяют `1` / `3` / `7` / `9` / `5` / `.`. Видов по осям — ортографические; орбитальное вращение возвращает перспективу.

## Позирование

| Клавиша | Требуется | Действие |
| --- | --- | --- |
| `P` | фокус во вьюпорте, выделен сустав | Закрепить или открепить выделенный сустав |
| `B` | выделен сустав | Изгиб сустава мышью: двигайте, чтобы повернуть, кликните, чтобы сохранить |
| `S` | выделен сустав | То же для бокового изгиба |
| `T` | выделен сустав | То же для скручивания |
| Левый клик или `Enter` | пока включён `B` / `S` / `T` | Сохранить результат |
| `Esc`, правый клик или та же клавиша ещё раз | пока включён `B` / `S` / `T` | Вернуть сустав в исходное состояние |
| `Esc` | в VR-режиме (где угодно в окне) | Выйти из VR-режима — см. [Режим VR](vr.md) |
| `Delete` или `Backspace` | фокус во вьюпорте, выделена модель | Удалить выделенную модель (очищает историю отмен) |
| `Ctrl+Z` | | Отменить |
| `Ctrl+Y` | | Повторить |

`B`, `S` и `T` работают независимо от того, какая панель имеет фокус клавиатуры (это клавиши **Правка → Поворачивать сустав мышью**); для `P` и `Delete` фокус должен быть во вьюпорте. Правка → Сбросить выбранный сустав, Сбросить конечность, Сбросить позу, Отразить позу и Отразить конечность на другую сторону не имеют клавиш; они находятся в меню Правка и (те, что относятся к отдельным суставам) в контекстном меню сустава.

## Приложение

| Клавиша | Действие |
| --- | --- |
| `F1` | Открыть это руководство |
| `Ctrl+N` | Файл → Новый — сброс сцены к состоянию после запуска |
| `Ctrl+O` | Файл → Открыть — загрузить проект `.pss` |
| `Ctrl+S` | Файл → Сохранить — сохранить сцену в её файл `.pss` (сначала запросит место, если его ещё нет) |
| `Ctrl+Shift+S` | Файл → Сохранить как… — сохранить сцену под новым именем `.pss` |
| `Ctrl+Q` | Выход |

## Менеджер ассетов

| Клавиша | Действие |
| --- | --- |
| `Enter` в поле поиска | Поиск |
| `F2` на коллекции | Переименовать её |
| Двойной клик по ассету | Импортировать его (`.obj`, `.duf`, `.dsf`) или открыть в его приложении |
| Двойной клик по папке | Открыть папку |
| Перетащить миниатюру | Изменить порядок (в Избранном и Коллекциях) или бросить на Избранное / Коллекцию в дереве |

## Вкладка окружения

| Жест | Действие |
| --- | --- |
| Перетащить по значению | Прокрутить его |
| Клик по значению | Ввести его; `Enter` подтверждает, `Esc` отменяет |
| Маленькая кнопка рядом со строкой | Вернуть этой настройке значение по умолчанию |

## Вкладка «Трансформация»

| Жест | Действие |
| --- | --- |
| Перетащить по регулятору | Прокрутить изгиб, боковой изгиб или скручивание выделенного сустава |
| Клик по регулятору | Ввести значение; `Enter` подтверждает, `Esc` отменяет |
| Маленькая кнопка рядом с регулятором | Вернуть этот регулятор в 0, позу покоя |

## Это руководство

| Клавиша | Действие |
| --- | --- |
| `Ctrl+F` | Поиск |
| `Enter` / `F3` | Следующее совпадение; `Shift+F3` — предыдущее |
| `Alt+Left` / `Alt+Right` | Назад / Вперёд |
| `Esc` | Закрыть |
