# Справочник по клавиатуре и мыши

Все элементы управления в одном месте. «Фокус вьюпорта» означает, что вы кликнули в 3D-виде после того, как в последний раз использовали другую панель; остальные сочетания клавиш работают независимо от того, какая панель находится в фокусе (текстовое поле, в котором вы печатаете, сохраняет собственный фокус клавиш).

## Мышь во вьюпорте

| Жест | Где | Что делает |
| --- | --- | --- |
| Левое перетаскивание | на суставе | Полнотелый IK: точка, за которую вы ухватились, следует за курсором, а тело следует за ней анатомически. |
| Левое перетаскивание | на пальце руки или ноги | Только этот палец сгибается к курсору; кисть, стопа и тело остаются на месте (с зажатым Ctrl или без него). |
| Левое перетаскивание | на пустом месте или на теле модели | Вращение камеры (орбита). |
| Ctrl + левое перетаскивание | на конечности или голове | Ограниченный IK: следует только та цепь, к которой принадлежит сустав — конечность до тела, голова и шея. Остальное неподвижно. |
| Ctrl + левое перетаскивание | на теле (бедра, живот, грудь) | Перемещает всю фигуру в текущей позе: ничего не привязано к полу, повороты суставов не происходят. Закрепленные суставы остаются на своих местах. |
| Левый клик | на модели | Выбрать её (синий контур); на пустом месте — снять выделение. |
| Левый клик | на суставе | Выбрать сустав (и сделать его фигуру активной). Клик по лицу выбирает голову. |
| Средняя кнопка мыши (перетаскивание) | где угодно | Панорамирование. |
| Колесо мыши | обычно | Зум. |
| Колесо мыши | при левом перетаскивании сустава | Двигать захваченную точку к камере (прокрутка вниз) или от камеры (прокрутка вверх). |
| Колесо мыши | при зажатых `X`, `Y` или `Z` с выбранным суставом | Вращать сустав вокруг этой оси шагами по 5°. |
| Правый клик | на модели или суставе | Контекстное меню: закрепить / открепить, сбросить сустав или конечность, отразить конечность, удалить. |

## Камера

| Клавиша | Действие |
| --- | --- |
| `1` / `Ctrl+1` | Вид спереди / сзади |
| `3` / `Ctrl+3` | Вид справа / слева |
| `7` / `Ctrl+7` | Вид сверху / снизу |
| `9` | Разворот на 180° |
| `5` | Исходный вид (стандартное кадрирование) |
| `.` | Вписать выделенное |

Клавиши работают на цифровом ряду и на цифровом блоке. Если NumLock выключен, клавиши `End` / `PageDown` / `Home` / `PageUp` / `Clear` (5) / `Del` на цифровом блоке заменяют `1` / `3` / `7` / `9` / `5` / `.`. Виды по осям являются ортографическими; вращение возвращает в перспективу.

## Позирование

| Клавиша | Условие | Действие |
| --- | --- | --- |
| `P` | фокус вьюпорта, сустав выбран | Закрепить или открепить выбранный сустав |
| `B` | сустав выбран | Сгибать сустав мышью: двигайте для поворота, кликните, чтобы зафиксировать |
| `S` | сустав выбран | То же самое для бокового изгиба |
| `T` | сустав выбран | То же самое для скручивания |
| Левый клик или `Enter` | когда включены `B` / `S` / `T` | Подтвердить результат |
| `Esc`, правый клик или повторный клик | когда включены `B` / `S` / `T` | Вернуть сустав в исходное состояние |
| `Delete` или `Backspace` | фокус вьюпорта, модель выбрана | Удалить выбранную модель (очищает историю отмен) |
| `Ctrl+Z` | | Отмена |
| `Ctrl+Y` | | Повтор |

`B`, `S` и `T` работают независимо от того, какая панель в фокусе (это клавиши команды **Правка → Поворачивать сустав мышью**); `P` и `Delete` требуют фокуса вьюпорта. Команды Правка → Сбросить выбранный сустав, Сбросить конечность, Сбросить позу, Отразить позу и Отразить конечность на другую сторону не имеют горячих клавиш; они находятся в меню «Правка» и (для отдельных суставов) в контекстном меню сустава.

## Приложение

| Клавиша | Действие |
| --- | --- |
| `F1` | Открыть это руководство |
| `Ctrl+N` | Файл → Новый — сбросить сцену до состояния нового запуска |
| `Ctrl+O` | Файл → Открыть — загрузить проект `.pss` |
| `Ctrl+S` | Файл → Сохранить — сохранить сцену в файл `.pss` (если файл не создан, сначала спросит, куда сохранить) |
| `Ctrl+Shift+S` | Файл → Сохранить как… — сохранить сцену под новым именем `.pss` |
| `Ctrl+Q` | Выход |

## Менеджер ассетов

| Клавиша | Действие |
| --- | --- |
| `Enter` в поле поиска | Поиск |
| `F2` на коллекции | Переименовать её |
| Двойной клик по ассету | Импортировать его (`.obj`, `.duf`, `.dsf`) или открыть в соответствующем приложении |
| Двойной клик по папке | Открыть папку |
| Перетаскивание миниатюры | Изменить порядок (в Избранном и Коллекциях) или перетащить в Избранное / Коллекцию в дереве |

## Вкладка Окружение

| Жест | Действие |
| --- | --- |
| Перетаскивание по значению | Изменение значения (скраб) |
| Клик по значению | Ввод значения; `Enter` — подтвердить, `Esc` — отмена |
| Маленькая кнопка рядом со строкой | Восстановить настройки по умолчанию |

## Вкладка Трансформация

| Жест | Действие |
| --- | --- |
| Перетаскивание по шкале | Изменение изгиба, бокового изгиба или скручивания выбранного сустава |
| Клик по шкале | Ввод значения; `Enter` — подтвердить, `Esc` — отмена |
| Маленькая кнопка рядом со шкалой | Вернуть значение шкалы в 0 (исходная поза) |

## Это руководство

| Клавиша | Действие |
| --- | --- |
| `Ctrl+F` | Поиск |
| `Enter` / `F3` | Следующее совпадение; `Shift+F3` — предыдущее |
| `Alt+Left` / `Alt+Right` | Назад / Вперёд |
| `Esc` | Закрыть |
